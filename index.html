Install Markly

Add Markly to your device so it opens like an app, even offline.

iPhone / iPad (Safari)
  1. Tap the Share button.
  2. Choose “Add to Home Screen”.
  3. Tap “Add”.
Android (Chrome)
  1. Tap the ⋮ menu.
  2. Choose “Install app” or “Add to Home screen”.
  3. Confirm.
Windows / Mac / Linux (Chrome or Edge)
  1. Click the install icon at the right of the address bar.
  2. Or open ⋮ menu → “Install Markly”.

Installing needs the site to be opened over https (or localhost).
